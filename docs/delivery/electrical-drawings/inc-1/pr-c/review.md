- **الطبقات والعقود:** `lint-imports` يعطي «9 kept, 0 broken»، ولا `ignore_imports` جديد، و`.importlinter` لم يتغيّر. ونطاق `drawings/domain` لا يستورد إلا المكتبة القياسية و`shared`. والتطبيق لا يستورد `fastapi` ولا `sqlalchemy` ولا `infrastructure`. و`electrical_bootstrap.py` جذر تركيب لعمليته، كما يجيز العقد 6. و`electrical_purge.py` لا يستورد أي وحدة.
