- [x] **المصادقة والصلاحيات تُفحص في الخلفية لكل مسار جديد**
  - `postMessage` محمي بـ `require(Permission.CONVERSATIONS_WRITE)` كتابع على المسار (`routers/conversations.py:369`). يعمل قبل المعالج، فالـ viewer يأخذ 403 قبل أي لمس للسجل (AC‑7.2)، والطلب بلا رمز يأخذ 401 (AC‑7.6). الاختباران: `test_a_viewer_is_refused_and_no_row_is_created`، و`test_no_or_a_bad_token_is_401_and_the_store_is_untouched`.

  - **الإعادة** لا تمر بالمنسّق، فلا تعيد فحص صلاحيات الوكيل. لا ثغرة اليوم، انظر SR‑2.
- [x] **عزل المستأجرين في الاستعلام وقاعدة البيانات**

  - **محادثة مساحة أخرى:** `get.execute` تحت RLS يعطي 404 قبل `claim_turn`. فلا يقرأ مفتاح مساحة أخرى شيئاً ولا يكتب، ولا يعبر المفتاح بين المحادثات (AC‑7.1، `test_another_workspace_cannot_reach_or_replay_the_key`).
  - **قراءة الإعادة:** `GetMessage` تشترط `conversation_id` و`workspace_id = ctx.workspace_id`، وترفض المحذوف ناعماً بـ 404 (`use_cases.py` `GetMessage`؛ `sql_repository.py:413-416`).
  - **`reply_to`:** لا يأتي من العميل أبداً، بل من سجل الدور في المنسّق.
    - الإدراج المحروس (`sql_repository.py:791-826`) يشترط رسالة `user` من المحادثة نفسها ومساحة الرسالة نفسها، داخل `EXISTS` تحت RLS.
    - الرفض `ValidationError` قبل `UPDATE` النسخة، فيُلغى كل شيء (`sql_repository.py:388-394`).
    - لا مسار يكشف وجود رسالة لعميل، فلا oracle.
    - اختبارات RLS الستة الجديدة: مرجع لمحادثة أخرى، ولمساعد، ولمستأجر آخر، وعدم الظهور لمستأجر آخر (`tests/integration/test_conversations_repository_rls.py`). تعمل في CI job `integration`، ولم تُشغَّل هنا.
  - **الترحيل `0009`:** عمود `uuid NULL` فقط. لا يغير RLS ولا المنح، فـ `tenant_isolation` وFORCE RLS يغطيان الصف كله.

  - **الإعادة:** قراءتان أوليتان بالمفتاح الأساسي، بلا تشغيل ولا فوترة، فهي أرخص من الدور.
  - **حجم السجل:** صف لكل إرسال **مقبول** فقط. الرفض قبل القبول (403/404/409/429) يحرّر الصف، وMISMATCH/REPLAY/IN_PROGRESS لا تُدرج. فالنمو تابع لنمو الرسائل نفسها (~700 بايت، يومان إلى ثلاثة).

  - **الكتابات المحمية (`_DETACHED`):** محدودة بعدد الأدوار المتزامنة بمفتاح (كتابة أو كتابتان لكل دور)، وكل كتابة محدودة بـ `statement_timeout` و`pool_timeout` القائمين. ليست نمواً غير محدود (SR‑5).

**ما فُحص ولم تظهر فيه ملاحظة:**
- **الإعادة ورؤية الصف الآن:**

  - ثم تقرأ رسالة المساعد كما هي الآن: المحذوفة ناعماً 404، فلا يعود نص حذفه المستخدم.
