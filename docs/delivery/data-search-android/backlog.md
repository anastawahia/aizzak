# جرد الملاحظات والديون المؤجلة بعد إغلاق ثغرات Data Search

- **التاريخ:** 2026‑11‑18.
- **الغرض:** ملف واحد يجمع كل ما وُثّق على أنه «لاحقاً» أو «مفتوح» أو «قرار للمالك» عند إغلاق الثغرات ث‑1…ث‑9.
- **الحالة العامة:** لا ثغرة عقد مفتوحة (`gaps.md`). ما هنا ديون ومخاطر مقبولة وتحسينات، ولا شيء منها حاجب.
- **المصادر المجرودة:** `gaps.md`، `acceptance.md`، `review.md`، `security-review.md`، `test-plan.md`، `retro.md`، `status.md` في المجلدات الخمسة:
  - `data-search-android` (ث‑1، ث‑4، ث‑6، ث‑8، ث‑9)
  - `data-search-message-status` (ث‑2)
  - `data-search-send-reconcile` (ث‑3)
  - `data-search-history-cursor` (ث‑5)
  - `data-search-deleted-pins` (ث‑7)
- **ما استُبعد:** كل ما أُصلح فعلاً في دورات التنظيف (مثل S‑4 في ث‑5، وSR‑1 و`exc_info` في ث‑3، وSR‑5 وSR‑6 في ث‑3).
- **الرموز:** «قرار» = ينتظر قرار المالك. «مقبول» = قرار المالك أن يبقى ويوثَّق فقط. «اختياري» = تحسين بلا موعد.
- **المراجع:** رقم ث‑N يعني الثغرة، والرمز بعده (SR، S، N) هو رمز الملاحظة داخل ملف تلك الثغرة.
