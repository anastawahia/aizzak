# §3.78 — المرحلة 8: القبول النهائي (Definition of Done) — 8.1 · 8.2 · 8.3

> عودة إلى الفهرس: [`INDEX.md`](INDEX.md) · التسليم الحيّ: [`../implementation-status.md`](../implementation-status.md) · الخطة: [`../implementation-plan.md`](../implementation-plan.md)
>
> **المصدر الملزِم:** [`Requirements-v1.md §14,§15`](../Requirements-v1.md) · [`implementation-plan.md` المرحلة 8](../implementation-plan.md) · [`09-testing-strategy.md`](../design/09-testing-strategy.md). **يبني فوق:** كل المراحل 0–7 (§2–§3.77).

المبدأ الحاكم: **القبول لا يُدَّعى بل يُثبَت بدليلٍ قابلٍ لإعادة التشغيل.** هذه المرحلة لا تكتب ميزةً جديدة؛ تُشغّل البوابات الخمس على حالة المستودع الراهنة، وتربط كلّاً من `AC‑01…16` باختبارٍ مسمّى أو عقدٍ أخضر، وتُشغّل الإثباتات الحيّة المطلوبة، وتُحصي مخرجات المورّد الثلاثة عشر — **وتُعلن الفجوات بصدق** لا تُخفيها.

## 3. مصفوفة `AC‑01…16` (الخلاصة — التفصيل في `acceptance-report.md §2`)

**16/16 مُحقَّقة.** أبرز الروابط:

- **AC‑01/02** طبقات ونطاق: `lint-imports` 8/0 + `mypy --strict` نظيف.
- **AC‑03** عزل الوحدات: عقد «Business modules do not import each other» KEPT **+ صفر FK عابر schema** (مسح الهجرات: كل FK داخل schemaها — `conversations→conversations` · `users→workspace.workspaces` · `chunk→knowledge.documents`).
- **AC‑04** Plugin: `test_agent_runtime.py::test_discovers_and_registers_every_valid_agent` + `::test_real_app_agents_tree_boots_with_all_five_agents_registered` + حيّ `test_orchestrator_live::test_an_unknown_agent_raises_404`.
- **AC‑05** عزل المستأجر: **121 اختباراً حيّاً**؛ `test_user_tenant_isolation_raw_select_cross_tenant_yields_zero_rows` + `test_forged_cross_tenant_*_is_rejected_by_rls_with_check` عبر العشر.
- **AC‑06** دورة الحياة: `test_agent_lifecycle.py` — النجاح/الفشل/الإلغاء، و`test_dispose_runs_exactly_once_on_every_path`.
- **AC‑07** عقد الـAPI: `test_api_conventions.py` (14) ثنائيّ الاتّجاه ضدّ `openapi.yaml` + `test_error_catalog.py`.
- **AC‑08** عقد الأحداث: `test_event_envelope.py` + حيّ `test_processed_events_live::test_a_double_published_event_registers_exactly_one_document` + 9 مخطّطات.
- **AC‑09** الجودة: البوابات الخمس §2.
- **AC‑10** الأسرار: `test_vault_secrets.py` (شكل Transit السلكيّ · مفتاح لا يفكّ آخر · رفض اجتياز المسار).
- **AC‑11** البثّ: `test_sse.py` (13) · `test_websocket_endpoint.py` (16) + حيّ من الحافّة (§3.76).
- **AC‑12** Workflow: `test_workflow_orchestration.py` (سلسلة مرتّبة · حلّ لكل خطوة).
- **AC‑13** `OQ‑01…06`: مُوقَّعة بتوقيع العميل 2026‑07‑10 (‏`00-detailed-design-decisions.md`).
- **AC‑14** توسّع الوحدات: `12-module-authoring-guide.md` + عشر وحدات مرجعيّة.
- **AC‑15** `integrations`: `test_connect_stores_cipher_ref_only` + ردّ نداء OAuth + تجديد كسول.
- **AC‑16** `usage`: حيّ `test_append_same_operation_id_is_idempotent_and_never_double_counts` — فرضٌ متزامنٌ بلا Streams.
