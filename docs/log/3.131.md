# §3.131 — د‑3: مسح الحقيقة الوثائقيّة

**التاريخ:** 2026‑08‑05  
**النطاق:** تعليقات ووثائق وأوصاف وسوم فقط؛ لا تغيير في سلوك `src/` أو التزويد أو حالة الخدمات.

## النتيجة

أُغلق سطح الترحيل الحالي على حقيقةٍ واحدة: PostgreSQL/PgBouncer/Redis/MinIO/Qdrant/Vault/التضمين تأتي من مكدّس Compose، وOllama وحدها خدمة systemd أصليّة داخل WSL. المحضن يقصد منشورات المضيف المزاحة، وملف `docker-compose.test.yml` الاختياري هو الذي ينشر التضمين ويُحضِر سكربت قاعدة الاختبار.

- صارت أوصاف `pyproject.toml` تطابق المنافذ: DB ‏15432 · Redis ‏16379 · MinIO ‏19000 · Qdrant ‏16333 · Vault ‏18200 · Ollama ‏11434 · embedding ‏8080 عبر ملف التجاوز.
- أزيلت رواية «Compose بالتوازي مع الخدمات الأصلية» من تعليقات `docker-compose.yml` و`.env.example` والوثائق الحية. وُصف `ollama-bridge` وفق الواقع: خدمة Ollama أصلية داخل WSL، والجسر 11435 → 11434 للحاويات.
- صارت مقدمة `tests/integration/conftest.py` ورؤوس اختبارات PostgreSQL/Redis/MinIO/Qdrant/Vault تصف الاعتمادات الحاويّة. لم يتغير سطر fixture أو ثابت أو اختبار.
- وُفّقت `09-testing-strategy.md` و`08-local-runbook.md` و`quickstart.md` و`stack-commands.md` مع ملف التجاوز و`.env.test` و`REQUIRE_LIVE=1` ووظيفة CI الحقيقية.
- كُنست أسطح نشطة لم يسمّها جدول د‑3 حرفياً لكنّها تحمل الادعاء نفسه: `ROADMAP.md`، مقدمة `deploy-linux-server.md`، وإحالة `deploy/minio/bootstrap.sh` المضللة إلى «أ‑2» الخطة المحذوفة. الإحالة الأخيرة صارت إلى سجلها التاريخي §3.99.
- أضيف رأس حالة حديث صغير إلى `implementation-plan.md` و`implementation-status.md`؛ السرد الطويل تحتهما معلن الآن أرشيفاً تاريخياً، ولم يُعَد كتابته.
- صُحّح تحذير الخطة عن العد: `pytest -rs` يطبع الملخص، بينما `--collect-only -q` يخرج `path: N` ويحتاج جمع العمود الثاني.

## ضلع MinIO الثالث

لم تُحذف الواقعة مع أرقام الأسطر القديمة:

1. التزويد يقرأ `MINIO_TEST_SECRET_KEY`.
2. المحضن يقرأ `TEST_MINIO_SECRET_KEY`.
3. `_MINIO_SECRET_DEFAULT` ما يزال `aizzak-test-secret`.

حارس د‑1 يرفض اختلاف الاسمين حين يكونان مضبوطين معاً قبل أول I/O، لكنه لا يوحّد الاسمين ولا يمنع غياب أحدهما. لذلك، بعد تدوير حساب الخدمة، تشغيل بلا `.env.test` يصل MinIO بالقيمة النائبة ثم يفشل `SignatureDoesNotMatch` بصوت عالٍ؛ لا يتخطّى. هذه الحقيقة موجودة الآن في استراتيجية الاختبار والقالب والدليل السريع ومرجع الأوامر.

## ما لم يتغيّر

- لا ملف تحت `src/` تغيّر.
- لا منطق Python أو shell أو Compose تغيّر؛ تعديلات هذه الملفات تعليقات فقط، عدا أوصاف وسوم pytest النصية.
- لا حاوية أُقلعت أو أُوقفت أو أُعيد إنشاؤها، ولا حجم حُذف. البوابة الكاملة أعادت بناء مخططات `aizzak_test` وشغّلت بذور الاختبارات ثم نظّفتها وفق fixtures القائمة؛ لم تُمس بيانات تشغيلية.
- السجلات والخطط المؤرخة التي تصف الحالة القديمة بقيت تاريخاً؛ صُحح سطح التشغيل الحالي وحده.
