## 3.18 ما بُني — المرحلة 2.3: محوّل Redis (`CacheProvider`) على Redis حيّ

**التنفيذ على خطوات مُبوَّبة (توجيه المستخدم — السياسة القائمة):** فحص (Redis ‏7.0.15 يعمل، `redis>=5.2` مُعلَنة أصلاً، redis‑py ‏8.0.1 في venv) ← المحوّل ← توصيل الجذر ← العدّة والاختبارات ← بوابات كاملة. نفّذه المُنسِّق مباشرةً (وحدة صغيرة ‑ 5 طرق؛ الخطة تُسنِد 2.3 لـ🛠️ بلا 📐).

| الطبقة | الملف | المحتوى |
|---|---|---|
| محوّل 2.3 | [`infrastructure/cache/redis_cache.py`](../src/app/infrastructure/cache/redis_cache.py) | `create_redis_client(RedisSettings)` (نمط مصنع `database.py`؛ `decode_responses=False` لعقد الـbytes + مهلتا socket ‏2ث fail‑fast) + **`RedisCache`** ينفّذ `CacheProvider` (02 §1.7) بنيوياً: `get`/`set(ex=ttl_s)`/`delete` idempotent/`incr`(INCRBY — يبدأ من `amount` لعدّادات النافذة الثابتة)/`expire` idempotent |
| توصيل | `framework/di/composition_root.py` | `redis_client: Redis` (للإغلاق `aclose()` — سابقة `engine`) + **`cache: CacheProvider`** (النوع = المنفذ)؛ استُهلك استثناء العقد #6 التطلّعي |
| عدّة | `pyproject.toml` (وسم **`live_redis`**) · `tests/integration/conftest.py` | مجسّ TCP ‏6379 → تخطٍّ آمن؛ **لا flush إطلاقاً** (خادم المستخدم قد يحمل بيانات) — كل اختبار تحت بادئة `aizzak-test:<uuid7>:` فريدة تُكنَس بعده (`scan_iter`+`delete`)؛ `TEST_REDIS_URL` قابل للتجاوز |
| اختبارات | [`tests/integration/test_redis_cache.py`](../tests/integration/test_redis_cache.py) | **12 حيّة**: bytes خام غير‑UTF8 حرفياً · مفقود→None · استبدال · TTL خادمي فعلي (قيمة `TTL` + **اختفاء حقيقي بعد 1.2ث** — عقد OAuth‑state) · بلا ttl→‏-1 · حذف/انقضاء idempotent · `incr` من الصفر ومع `amount` وفوق `set(b"10")`→11 · **ترجمة فشل الاتصال** (منفذ مغلق→`AppError common.internal` فوراً، لا استثناء redis خام) |

**قرار سياسة الأخطاء (المُنسِّق):** **ترجمة لا fail‑open** — كل فشل Redis ⇒ `common.internal` (سابقة R6 في كل المحوّلات). السبب: `CacheProvider` ليس تحسيناً فقط — يخدم ربط OAuth `state` الأمني (fail‑closed CSRF)، وانقطاعٌ مُقنَّع كـ«miss» لا يُميَّز عن هجوم ويصعب تشخيصه؛ الـfail‑open الكاشي (نمط `alpha`) سياسة مستدعٍ إن لزمت، لا سياسة محوّل.

**بوابات 2.3:** ruff **328** · mypy **278** · **8/0** · junit **724** (+12) · تكامل **123/123**.
