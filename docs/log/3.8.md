## 3.8 ما بُني — المرحلة 3 مجموعة (ج): `knowledge` 3.k1 (المُحلّلات)

**النطاق المقصود:** المُحلّلات الخمسة (PDF‑نصّ · Excel · OCR/صورة · JSON · نصّ) مع **استبدال غلاف `llama_index.Document`/dict بنوع مخرَج محايد**. إعادة استخدام شبه مباشرة من `alpha/rag/parsers/` (♻️، السلسلة 🔍✅ ← 📐 [استقصاء + حصاد `refs/parsers.md` المُجمّد] ← 🛠️ ← ✅). نُفِّذ عبر وكيل `implementer` واحد + تحقّق مركزي مستقلّ.

> **مختلف عن الشرائح النقية:** المُحلّلات **محوّلات** (تستورد مكتبات تقنية) لكنها **لا تحتاج Docker** (مكتبات محلّية) ⇒ بُنيت واختُبرت كاملةً الآن، خلافاً لمحوّلات SQL المؤجّلة.

**قرارات/تفاصيل:**
- **النوع المحايد** يوحّد عقدَي `alpha` (dict‑RAGFlow + Document‑stream) في `ParsedChunk`. البيانات الوصفية الغنية (page_number/headers/table_name…) تُحمَل في `metadata: Json` — **مخطّط payload الـQdrant قرار مؤجَّل** (3.k3/3.k4).
- **`order` ترتيب بنيوي حتمي** (صفحة/ورقة·مقطع) لا ترتيب معالجة — يمهّد لثبات `Chunk.seq` (INV‑K1) لاحقاً.
- **المنفذ متزامن** (fitz/pandas/tesseract محجوبة CPU) — عامل `knowledge` اللامتزامن يفرّغ عبر `asyncio.to_thread` مستقبلاً.
- **`OCR_LANG="ara+eng"`** (عربي‑أولاً، مخالِفاً كود `alpha` `eng+ara` ومطابقاً README + توجّه المنصّة)؛ OCR يتدهور بلطف عند غياب ثنائي tesseract (يعيد `""` لا يرمي).
- **⚠️ بند مفتوح:** **PyMuPDF ترخيص AGPL/تجاري مزدوج** — موروث من اختيار `alpha`؛ يُحسَم عند تغليف عامل `knowledge` للنشر.
- **مؤجَّل صراحةً (خارج 3.k1):** PDF‑tables (Camelot→Ghostscript، AGPL) · DOCX (python‑docx) · التقطيع العميق (`node_builder`: دلالي/نافذة‑جملة/parent‑chunk/تفجير صفوف الجداول) → 3.k2/3.k3 · نطاق+مستودع+هجرة+RLS لـ`knowledge` → **3.k4**. مهلة `SIGALRM` لكل ملف لم تُنقَل (مهلة عامل لاحقاً). `.xls` غير موجَّه (يحتاج xlrd).
- **الحدود مُتحقَّقة:** نطاق/تطبيق/`repository`/`inbound`/`sql_repository` لـ`knowledge` **ما زالت فارغة** (3.k4)؛ نقاء المنفذ واستقلال الوحدة أخضران (`lint-imports` 8/0، تحقّق مستقلّ).
