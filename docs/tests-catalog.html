كيف تُشغَّل

الإعداد كلّه في pyproject.toml تحت [tool.pytest.ini_options]: لا يوجد pytest.ini. المسارات testpaths=["tests"]، وpythonpath=["src","."] (النقطة تُتيح استيراد services.embedding.app)، وasyncio_mode="auto" فلا حاجة لوسم asyncio، وaddopts="-q --strict-markers" فأيّ وسمٍ غير معلَنٍ يُرفَض.

البوّابات الخمس — التشغيل الكامل

الترتيب أرخصُ أوّلاً: تنسيق ← فحص ← أنواع ← حدود الاستيراد ← الاختبارات. هذا نصّ README.md نفسه، ويُشغَّل داخل WSL لأنّ أدوات .venv لينكسيّة.

الحزمة كلّها (وحدة + معمارية + تكامل)

بلا مُرشِّح -m: كلّ ملفات tests/integration/ محميّةٌ بوسم live_* يسبر خدمته ويتخطّى بأمانةٍ حين تتعذّر، فتمرّ على جهازٍ بلا بنيةٍ تحتيّة. و-rs يطبع اسم وسبب كلّ تخطٍّ بدل إخفائه خلف علامةٍ خضراء.

cd /home/AIZZAK && .venv/bin/pytest -rs

الوحدة والمعمارية فقط — سريع، بلا أيّ خدمة

cd /home/AIZZAK && .venv/bin/pytest tests/unit tests/architecture

ملاحظة من الذاكرة التشغيليّة: سطر الملخّص النهائيّ لـpytest يغيب أحياناً في هذه البيئة. للقراءة الموثوقة استعمل تقرير JUnit:

cd /home/AIZZAK && .venv/bin/pytest --junit-xml=/tmp/r.xml -q
python3 -c "import xml.etree.ElementTree as E;print(E.parse('/tmp/r.xml').getroot().attrib)"

التكامل الحيّ — يحتاج مكدّس Compose

أقلِع البنية، ثمّ حمّل .env.test في البيئة قبل pytest. نسيان التحميل لم يعد يُنتج أخطاءً منذ b10b53e: كلّ مسبارٍ حيٍّ يُجري مصافحةً حقيقيّة ويتخطّى بصدق.

docker compose -f docker-compose.yml -f docker-compose.test.yml up -d
cd /home/AIZZAK && set -a; . ./.env.test; set +a
.venv/bin/pytest tests/integration -rs

ولجعل الغياب فشلاً صريحاً بدل تخطٍّ — وهو ما تفعله CI:

REQUIRE_LIVE=1 .venv/bin/pytest -rs \
  -m "not live_ollama and not live_embedding and not live_openai and not live_web_search"

حزمة القياس (eval) — ليست اختباراً

لا يجمع pytest شيئاً من tests/eval/: لا ملفّ فيها يبدأ بـtest_. المحضن يحتاج مكدّساً حيّاً وفهرساً مبنيّاً، وذلك خطوة runbook لا مهمّة fixture.

docker cp tests/eval aizzak-app-1:/tmp/eval
docker exec -e EVAL_WORKSPACE=<uuid> -e EVAL_USER=<uuid> -e EVAL_SPACE=<uuid> \
  -e EVAL_VARIANTS='[{"name":"shipped"},{"name":"floor","min_bm25_score":25.0}]' \
  aizzak-app-1 python /tmp/eval/run_calibration.py > run.jsonl
