## 3.12 ما بُني — المرحلة 3 مجموعة (ج): وحدة `media` (شريحة نقية + هجرة/RLS)

**قرارات وحدة `media`:**
1. **فصل التحقّق (سابقة `files` حرفياً):** الـVO `GenParams` يتحقّق من **الشكل** حسب النوع؛ **السقوف الرقمية** (`Limits.max_image_dim=2048` · `max_video_seconds=30` من `07 §4`) تُفرَض في `RequestMedia` برمز `media.invalid_params` — لا أرقام صلبة في الوحدة. انتهاك الشكل → كود عام `common.validation`؛ انتهاك السقف → `media.invalid_params` (يطابق `03 §4`).
2. **`GenParams` يحمل `kind`** كي يتحقّق `__post_init__` من التركيبة أياً كانت نقطة البناء (`from_dict` لا يكرّر منطقاً).
3. **مقعد `MediaGenerator` منفذ وحدة محلي** (لا استيراد لمنافذ الإطار في التطبيق): يعيد `result_file_id`؛ تركيبته الحقيقية (مزوّدو التوليد + تخزين الناتج عبر `files`) شأن عامل م5 — يماثل قرار `knowledge` §3.11‑6.
4. **لا `ports/inbound.py`** — لا مستهلك عابر للوحدات بعد (كحال `conversations`/`memory`)؛ يُضاف عند ربط وكيلَي Image/Video (م4.7).
5. **اختبار المخططات ارتقى عن نمط `knowledge`:** بدل التأكيدات اليدوية فقط، تحقّق فعلي بمكتبة `jsonschema` (تبعية مُعلَنة كانت غير مستعملة) + اختبارا نفي يثبتان أن الفرض حقيقي. *(ملاحظة verifier: `format: uuid` غير مفروض — تحقّق شكلي للحقول/الأنواع.)*
6. **ملاحظتا verifier غير حاكمتين:** (أ) توقيع `MediaRequested` المختصر في `06 §8` لا يذكر `prompt/params/agent_key` — المخطط JSON هو المرجع الملزِم وهو مُطابَق. (ب) انحراف تسمية موروث في الإطار (`common.validation` مقابل `common.validation_error` في `03 §4`) — موجود قبل هذه الخطوة ويخص كل الوحدات؛ يُحسَم عند طبقة API (م6). ثغرات تغطية دقيقة (فرع height · حد طول `AgentKey` · اختبارات نفي للمخططين الأبسط) موثَّقة في تقرير verifier للطور القادم.
